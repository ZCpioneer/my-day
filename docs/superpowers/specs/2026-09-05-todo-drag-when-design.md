# 朝暮：长按拖动改今天 / 以后

日期：2026-09-05  
状态：已实现  
承接 `2026-09-05-todo-swipe-delete-design.md`、`2026-09-05-tidy-today-and-later-design.md`

## 要解决的问题

待办页「今天」和「以后」现在只能靠自动整理改。勾选和左滑删除都在，人手动把一条从今天拖到以后、或从以后拖回今天，做不到。

## 做法

「今天」「以后」里**未完成**的条目可以长按拖到另一栏。只改这一条的 `when`。不走确认框：这是用户自己动手，不是 Agent 写入。

已完成不能拖。点一下取消勾，回到它原来的「今天」或「以后」。

## 手势

按住约 450ms、期间位移小于 8px，这一条才抬起来。已经打开的左滑先收回。同时只抬一条。

三种手势互不抢：

| 一开始的动作 | 结果 |
|---|---|
| 横滑 | 仍是左滑删除 |
| 竖滑 | 仍是滚列表 |
| 按住后再动 | 拖动改栏 |

点一下仍是勾选 / 取消勾。长按成功后这次抬手不勾选。

拖的时候列表不跟手指走。手指靠近列表顶或底约 36px 内，列表再轻轻自动滚，好让另一栏露出来。

Android 上长按不弹出系统菜单、不选中文字（条目已有 `user-select: none`，拖时还要挡住 `contextmenu`）。

## 松手

落点按手指的纵坐标，对上哪一栏的区域就算哪一栏：

- **今天**：从「今天」栏标题到「以后」栏标题之前（含今天的空状态文案）
- **以后**：从「以后」栏标题到「已完成」栏标题之前（含以后的空状态文案）
- **已完成、页外、自己原来那一栏**：弹回，不改 `when`

空的「以后」也能接住。拖到栏标题上算放进这一栏。

换到另一栏立刻写入。同一栏里的先后这次不改，不新增排序字段；条目从一栏消失、出现在另一栏，位置跟现有 `list()` 顺序走。

人手动拖到今天时，**不卡 4 条上限**。那条上限只约束自动整理。

下一次「自动整理待办」仍会按聊天把两栏重新排一遍。

## 观感

抬起：略放大、带一点阴影，原来位置留空槽。目标栏（今天或以后）有一圈浅色提示。弹回或落下用现有 `--ease`，大约 180–220ms。

系统若支持振动，抬起时短振一下（`navigator.vibrate`，不加新插件）。`prefers-reduced-motion` 时不放大、不跟手飞，松手在另一栏则直接改 `when`。

标题右侧提示改成：`左滑删除 · 长按调栏`。

## 数据

`todoRepo.setWhen(id, "today" | "later")`：找到这条，只改 `when`，不动 `status` / `completedAt`。找不到则抛错，和 `toggle` 一样。

不删条目。不改日记。不改对话。

## 不改

三页底栏、日记四段、设置、单机安卓、自动整理流程、Agent 仍须确认才写入待办、左滑删除、点按勾选、栏内排序、拖到已完成、第二层确认、撤销条。
