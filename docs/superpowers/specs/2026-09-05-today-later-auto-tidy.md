## 待办三层

从上到下：

1. **今天**：`status === "open"` 且 `when !== "later"`（缺省当今天，兼容旧数据）
2. **以后**：`status === "open"` 且 `when === "later"`
3. **已完成**：今天勾掉的（`completedAt` 的本地日期是今天）。更早勾掉的不显示。

顶栏计数只算今天：今天已勾 / （今天未完成 + 今天已勾）。以后不计入。

以后也可以勾，勾了进当天已完成。日记的「没做完」只看今天未完成。

待办页只打卡，不手动新建。

## 今天的清单何时变

过夜不改 `when`。没对话、只打卡的人，今天那几件继续留在今天。

只有用户确认「今日计划」才刷新：

- 选中的 → `when: "today"`（已有则改分区，没有则新建）
- 原来在今天但没选的 → `when: "later"`
- 白天随口记下的新事 → 默认 `when: "later"`

不确认，待办不动。

## 自动整理

位置仍是发送左边。**朝 / 暮切换、点了写日记，已作废**，见新 spec。自动整理只刷新今日待办。

## 工具

| 工具 | 作用 |
| --- | --- |
| `list_todos` | 读今天 / 以后 / 今日已完成 |
| `propose_todos` | 提议新事项，默认进以后；确认后才写入 |
| `set_today_plan` | 提议今天这几件（可含已有标题或新标题）；确认后整表替换今天分区 |
| `suggest_order` | 只建议顺序，不改列表 |
日记不再走对话工具，见新 spec。

Agent 不能勾掉任务。待办不能直接写库。

## 数据

`DayChat.planConfirmedAt?: string`。确认今日计划时写入。新的一天没有这个字段。
